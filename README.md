# 🚀 Warefy - AI-Powered Supply Chain Dashboard

A modern, full-stack supply chain management platform with AI capabilities, real-time analytics, and warehouse visualization.

## ✨ Features

- 📊 **Advanced Analytics & Reporting** - Real-time dashboards with charts and AI insights
- 🤖 **AI Command Center** - Natural language queries powered by OpenAI
- 📦 **Order Management** - Track and manage orders with status updates
- 🏭 **Warehouse Management** - Visual map editor for warehouse layouts
- 🔗 **Integration Hub** - Connect with Shopify, WooCommerce, Slack, and more
- 👥 **User Management** - Role-based access control with 2FA support
- 💰 **Financial Tracking** - Revenue analytics and financial reporting
- 🔔 **Smart Notifications** - Push, email, and SMS notifications

## 🛠️ Tech Stack

**Frontend:**
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Recharts for data visualization
- Axios for API calls

**Backend:**
- FastAPI (Python)
- SQLAlchemy ORM
- PostgreSQL (production) / SQLite (development)
- OpenAI API integration
- JWT authentication

## 🚀 Deployment

### **Option 1: Deploy to Render (Recommended)**

1. **Push to GitHub:**
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/warefy.git
   git branch -M main
   git push -u origin main
   ```

2. **Deploy Backend on Render:**
   - Go to [render.com](https://render.com) and sign up
   - Click "New" → "Blueprint"
   - Connect your GitHub repository
   - Render will automatically detect `render.yaml` and create:
     - PostgreSQL database
     - Backend web service
   
3. **Set Environment Variables on Render:**
   - `OPENAI_API_KEY` - Your OpenAI API key (required for AI features)
   - `SECRET_KEY` - Auto-generated by Render
   - `DATABASE_URL` - Auto-set by Render

4. **Deploy Frontend on Vercel:**
   ```bash
   cd frontend
   npx vercel
   ```
   
5. **Set Frontend Environment Variable:**
   - In Vercel dashboard, add:
   - `NEXT_PUBLIC_API_URL` = `https://your-backend-url.onrender.com`

### **Option 2: Local Development**

1. **Backend Setup:**
   ```bash
   # Install Python dependencies
   pip install -r requirements.txt
   
   # Start backend server
   ./start_backend.sh
   # Or manually:
   cd backend && uvicorn main_lite:app --reload
   ```

2. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Access the application:**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
   - API Docs: http://localhost:8000/docs

## 📝 Environment Variables

### Backend (.env)
```bash
DATABASE_URL=postgresql://user:pass@host:port/db  # Production only
SECRET_KEY=your-secret-key
OPENAI_API_KEY=your-openai-api-key
```

### Frontend (.env.local)
```bash
NEXT_PUBLIC_API_URL=http://localhost:8000  # Local
# NEXT_PUBLIC_API_URL=https://your-backend.onrender.com  # Production
```
